# 👁️ BLINDTECH

**Blindtech** is a sophisticated, multi-round elimination platform designed to evaluate social strategy, technical logic, and psychological resilience in a high-stakes competitive environment.

---

## 🖤 THEME & PHILOSOPHY

The project adheres to a **Dystopian Monochrome** aesthetic—premium high-contrast design, bold typography, and a "System-driven" narrative. In this void, communication is a privilege, and every decision is a calculated risk.

---

## � PROJECT STRUCTURE

The documentation is organized to provide clarity without redundancy:

- **[Game Manual](docs/GAME_MANUAL.md)**: The definitive guide to gameplay. Contains detailed round breakdowns, scoring formulas (Math), and official laws of the System.
- **[Development Guide](docs/DEVELOPMENT.md)**: Technical specifications for engineers. Covers environment setup, backend architecture, and WebSocket protocols.

---

## 🕹️ CORE SYSTEM COMPONENTS

1. **The Pulse (Metrics)**: Life is measured via **Hearts** and **Momentum**. Depletion of either results in immediate de-calibration (elimination).
2. **The Silence Rule**: Many rounds enforce absolute communication blackouts. Violation terminates the participating unit.
3. **The Unit (Pacts)**: Permanent pairings formed early in the trials intertwine the fates of participants.
